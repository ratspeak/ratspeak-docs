# rsNode

rsNode is firmware for Heltec LoRa boards: the Heltec V3, and the Heltec V4 in its R2, R8, and R8 TFT variants. A board running rsNode is either:

- **a radio for an app**, used by Ratspeak or another Reticulum app over USB, Bluetooth, or Wi-Fi; or
- **a Repeater** that relays Reticulum traffic over LoRa on its own, with optional TCP links over Wi-Fi.

rsNode is in private beta. Beta testers install it from the **rsNode** tab of the [web flasher](https://ratspeak.org/flash.html).

## The rsNode guide

The full guide covers installing rsNode, the button and screens, Bluetooth and Wi-Fi, running a Repeater, settings, managers, updates, remote management, troubleshooting, and recovery. It is at **[ratspeak.org/rsnode.html](https://ratspeak.org/rsnode.html)** and opens with the same beta password as the flasher.

For a beta password, email [mail@ratspeak.org](mailto:mail@ratspeak.org).
