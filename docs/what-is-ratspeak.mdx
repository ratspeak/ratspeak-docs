# What is Ratspeak?

Ratspeak is a family of communication tools built around [Reticulum](https://reticulum.network/). The desktop and mobile app gives you private messaging, file sharing, Channels, turn-based games and experimental voice calls. You create an identity on your device; there is no account to register or phone number to provide.

You can connect over the internet, a local network, Bluetooth or compatible LoRa radios. Which connections you can use depends on your device and setup. Reticulum can work without the public internet, but there still needs to be a usable path between the people or nodes communicating.

## What's in the box

- [Ratspeak](./products/ratspeak.md) is the desktop and mobile app.
- [Ratspeak Handheld](./hardware/handheld-guide.md) is the unified firmware for [T-Deck Plus](./products/rsdeck.md), [T-Pager](./hardware/handheld-guide.md), [Cardputer Adv](./products/rscardputer.md) and M9. The available modes depend on the board. It succeeds the historical rsDeck, rsPager and rsCardputer projects.
- [rsReticulum](./products/rsreticulum.md) and [rsLXMF](./products/rslxmf.md) provide the Rust networking and messaging stack, with standalone tools for operators and libraries for developers.
- [rsLXST](./products/rslxst.md) supplies experimental voice and media transport over Reticulum.
- [LRGP](./products/lrgp.md), [LXMFace](./products/lxmface.md) and [Ratkey](./products/ratkey.md) cover game messages, identity avatars and experimental hardware identity work.

You do not need to install all of these to use the app. The [ecosystem guide](./concepts/ratspeak-ecosystem.md) explains how the pieces fit together and distinguishes standalone releases from the libraries bundled in Ratspeak.

## Built on Reticulum

Reticulum handles identities, packets and paths across different kinds of connection. [LXMF](./concepts/links-and-lxmf.md) adds messages and delivery methods. A TCP connection can carry traffic across the internet; a radio connection can carry it without an internet service. Transport nodes can forward packets between those connections.

Direct conversations are end-to-end encrypted. An [Offline Inbox](./using-ratspeak/network-and-peers.md#offline-inbox) uses a propagation node to store recipient-encrypted messages for later pickup. [Channels](./using-ratspeak/messaging-and-contacts.md#channels) use hubs that can read the messages they distribute. These are different roles, so choose the one that fits the conversation.

A connection is still required to send or receive. Offline Inbox delivery also depends on a reachable propagation node and its storage and retention policy; it cannot guarantee delivery through a disconnected network.

## Who it's for

- People who want messaging without a central account or a phone number tied to their identity.
- Field operators using radios where cellular or internet service is unavailable.
- Community network builders connecting neighbors and maintaining transport or propagation nodes.
- Tinkerers, radio operators and developers building tools on Reticulum and LXMF.

For radio hardware, start with [RNode and Supported Boards](./hardware/rnode-and-supported-boards.md). For an always-on node, see [Infrastructure & Ops](./deployment/infrastructure-and-ops.md).

## Limits to understand

Ratspeak is in alpha, and handheld firmware is in beta. Voice features are experimental. Check the relevant product and setup pages for platform, hardware and interoperability limits.

Encryption does not make you anonymous. Other nodes can observe network activity, and IP-based connections still use IP addresses. Read [Cryptography & Protection](./concepts/cryptography-and-protection.md) before relying on Ratspeak for a particular privacy need.

For questions about current behavior, see the [FAQ](./reference/faq.md). If something is not working, use [Troubleshooting](./reference/troubleshooting.md).
