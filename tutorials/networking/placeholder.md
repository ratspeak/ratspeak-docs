# Set up a connection

Start with the connection you have available. A new Ratspeak profile needs an enabled interface before it can reach peers.

- **Two devices on the same local network:** follow [Your First Session](/docs/getting-started/your-first-session), including Local Network permissions and discovery.
- **A TCP connection to a known node:** use [IP, Internet & I2P](/docs/networking/ip-internet-and-i2p). Enter the operator's current address and port.
- **Bluetooth between supported devices:** check the platform and central/advertiser roles in [Bluetooth Interfaces](/docs/networking/bluetooth-interfaces).
- **A LoRa radio attached to the app:** identify the board and firmware in [RNode and Supported Boards](/docs/hardware/rnode-and-supported-boards), then follow [LoRa & RNode](/docs/networking/lora-and-rnode).
- **A standalone handheld:** use the [Handheld Guide](/docs/hardware/handheld-guide) for the supported modes and board controls.

After the interface is online, announce and exchange a test message as described in [Your First Session](/docs/getting-started/your-first-session). An online interface alone does not prove that there is a path to the person you want to reach.

If the peer does not appear or a message stays pending, work through [Troubleshooting](/docs/reference/troubleshooting). For transport or Offline Inbox hosting, continue with [Infrastructure & Ops](/docs/deployment/infrastructure-and-ops).
