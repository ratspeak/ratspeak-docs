# Tutorials

These walkthroughs cover hardware flashing and help you find the right networking setup guide. Check each guide's board and firmware requirements before following its commands.

For your first app session, start with [Install and Platform Setup](/docs/getting-started/install-and-platform-setup) and [Your First Session](/docs/getting-started/your-first-session). If the app is installed already, choose [a connection](./networking/placeholder.md).

For configuration, everyday use and protocol details, browse the [docs](/docs). You can also ask for help in the [community Discord](https://ratspeak.org/discord).
